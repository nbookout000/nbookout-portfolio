# nbookout portfolio

A React + Vite rebuild of the supplied portfolio page. The page data is centralized in `src/data/portfolio.js`, while layout and interactions live in reusable React components.

## Run locally

```sh
npm install
npm run dev
```

## Add the original artwork

Place the source artwork in `public/` using the paths referenced in `src/data/portfolio.js`, for example `public/poster/poster1.jpeg` and `public/print/project1-1.jpg`. Add `public/wires5.png` for the homepage skyline.
